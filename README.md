# 🎬 Catálogo de Filmes

Aplicação desenvolvida em React que consome a API do TMDB para listar, pesquisar e visualizar informações de filmes.

O projeto também possui sistema de favoritos com dados armazenados no navegador.

## 🚀 Funcionalidades

- Listagem de filmes populares
- Pesquisa de filmes por nome
- Página de detalhes de cada filme
- Poster
- Nota
- Ano de lançamento
- Duração
- Gêneros
- Sinopse
- Sistema de favoritos
- Página de favoritos
- Favoritos salvos no LocalStorage
- Loading durante requisições
- Tratamento de erros
- Layout responsivo

## 🛠️ Tecnologias

- React
- JavaScript
- Vite
- React Router
- TMDB API
- LocalStorage
- CSS
